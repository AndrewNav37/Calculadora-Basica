# Calculadora Básica

¡Bienvenido a **Mi Primer Proyecto**! Esta es una calculadora sencilla pensada para resolver operaciones matemáticas básicas y algunas funciones avanzadas.

## 📝 Descripción
Esta aplicación está diseñada para resolver:
* Sumas y restas
* Multiplicaciones y divisiones
* Raíces cuadradas
* Potencias
